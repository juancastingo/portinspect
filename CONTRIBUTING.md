# Contributing to portinspect

Thank you for your interest in contributing to `portinspect`!

## Development Setup

```bash
git clone https://github.com/juancastingo/portinspect.git
cd portinspect
pip install -e ".[dev]"
pytest
```

## Guidelines

- Keep the library lightweight with **zero third-party dependencies**.
- Maintain clean cross-platform fallbacks and typing annotations.
